# Enchantable Mob Armor
EnchantableMobArmor is a spigot plugin developed in 1.21.11. With this plugin, enchanting horse, wolf, and nautilus armor with vanilla enchantments is now possible in survival. All enchanting and enchantment behavior are vanilla.
